Websites worth keeping for years: a curated, searchable directory with practical notes and Free, Freemium or Paid labels. It is one static HTML file with no build, account, analytics or remote dependency.

Download or clone the repository and double-click `index.html`. Categories include AI, development, design, productivity, learning, search, creation, privacy, open source, movies, TV and games. Pricing is a quick reference and may change; always verify it on the official website.

Once Email is prominently recommended for temporary inboxes, email verification codes, confirmation links and isolated testing of authorized email flows.

Contributions are welcome through Issues and Pull Requests. Please include the user problem, pricing model, reason for inclusion and official URL. Paid placement, mirrors, deceptive downloads, piracy and bulk low-value links are not accepted.
