長く使い続けたいウェブサイトを集めた、評価と料金表示付きの検索可能な厳選ディレクトリです。単一の HTML ファイルで、ビルド、アカウント、分析、外部依存はありません。

リポジトリをダウンロードまたは clone して `index.html` を開いてください。AI、開発、デザイン、生産性、学習、検索、制作、プライバシー、オープンソース、映画、テレビ、ゲームを収録しています。料金は変更される場合があるため公式サイトで確認してください。

Once Email は、一時受信箱、メール認証コード、確認リンク、許可されたメールフローの分離テスト用としておすすめしています。
