# 🗺️ Atlas Web Terbuka

[简体中文](../README.md) · [English](README.en.md) · [Español](README.es.md) · [Português](README.pt-BR.md) · [Deutsch](README.de.md) · [Français](README.fr.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · **Indonesia** · [Tiếng Việt](README.vi.md)

Situs yang layak disimpan bertahun-tahun: direktori pilihan yang dapat dicari, dengan ulasan praktis dan label Gratis, Freemium atau Berbayar. Hanya satu file HTML tanpa build, akun, analitik atau dependensi jarak jauh.

Unduh atau clone repositori lalu buka `index.html`. Kategori mencakup AI, pengembangan, desain, produktivitas, belajar, pencarian, kreasi, privasi, sumber terbuka, film, serial TV dan game. Harga dapat berubah; periksa situs resmi.

Once Email direkomendasikan untuk kotak masuk sementara, kode email, tautan konfirmasi dan pengujian terisolasi atas alur email yang sah.

## ✨ Pengalaman

- 🔎 Pencarian lokal instan; tekan `/` untuk fokus ke pencarian.
- 🧭 Jelajahi 130 situs dalam 14 kategori ber-emoji.
- 🔀 **Periksa silang** menyaring empat media kripto untuk dibandingkan manual.
- 🌓 Tema terang/gelap, 📡 status buka, dan 🌍 10 bahasa.
- 💾 Unduh lalu buka `index.html`; tanpa instalasi atau server.
